# 尾文字Z / OMOJI Z — CLASSIC REMASTER 4.2

クラシック版を基盤にしたリメイクです。標準の入口は `index.html`。従来の全512台・256コースと、公式戦・グランプリ・ガレージ・塗装屋・ショップ・記録/対戦・運営機能をそのまま利用できます。

## 4.2の品質改善

- コース図を拡大して確認でき、距離・スタートとゴールを出走前に把握できます。
- 初回の読み込み状況と接続エラーを表示し、失敗時は再読み込みできます。
- 設定中のキー/ゲームパッド入力で背後のレースが再開する問題を修正。
- 影の投影を安定化し、画質切替や高解像度画面での描画負荷を改善。
- スマートフォンの操作領域・表示、キーボードのフォーカスとダイアログを調整。

詳細と確認範囲は[4.2の変更記録](docs/QUALITY_4_2.md)を参照してください。

## リメイク内容

- レースを中心にしたメニュー、車両情報、ガレージ、ショップ、走行HUDのデザインを刷新。
- 全256コースについて、実際の走行座標から生成したコース図を出走前に表示。
- WebGLの車体照明・反射・影、ソフトウェア描画の天候表現を改良。
- PC・スマートフォン向けの画面構成。タッチ操作と既存の3つの操作プリセットを維持。
- 既存の33曲（メニュー1曲＋レース8テーマ×4ミックス）を引き続き使用。

車両の性能、価格、報酬、強化ルール、周回判定を今回の表示変更によって置き換えていません。詳しい仕様は[クラシック版の説明](docs/CLASSIC_V3.md)、互換性と確認範囲は[リメイクの説明](docs/CLASSIC_REMASTER.md)を参照してください。

## セーブと旧URL

同じブラウザ・同じドメインなら、クラシック版の所持車・所持Z・強化・記録などを引き続き読み込みます。既存の保存キーを変更していません。別端末への移行にはゲーム内バックアップを使用してください。

`legacy.html` は `index.html` へ移動し、車両/コース指定と画面指定を保持します。車種・コースの詳細ページからの起動も継続します。前回の別エンジン版は `reborn.html` に残していますが、標準のゲームはクラシック版です。別エンジンの進行データをクラシックの進行へ上書きすることはありません。

## ブランチからmainへ自動統合

mainから作業ブランチを作成してpushすると、**mainと統合した状態のテストと公開用ファイル生成が成功した場合だけ**自動でmainへ取り込み、GitHub Pagesの公開を起動します。競合や保護ルールで拒否された変更は統合しません。条件と失敗時の確認先は[自動統合の説明](docs/AUTO_MERGE.md)に記載しています。

公開ドメインと既存CNAMEは維持します。

## 開発・検証

Node.js 22推奨。jsdomは開発テスト専用で、プレイヤーにnpmは不要です。

```sh
npm ci --ignore-scripts
npm test
npm run dev
python3 tools/build-site.py --out /tmp/omoji-public
```

`npm test` はクラシックの画面接続・カタログ・保存互換性、コース図の一致、全車両の性能と経済、走行・通信・音楽・静的ページ、自動統合処理、保持している別エンジン版を検証します。GPU画像や実機FPSは自動テストだけでは保証できません。確認した範囲は `VERIFICATION.txt` に記載します。

## 主なファイル

- `index.html` / `assets/game.js`：クラシックのゲーム本体。
- `assets/classic-remaster.css` / `assets/classic-remaster-ui.js`：新しい画面とコース図の表示。
- `assets/classic-visuals.js`：クラシックの描画改善。
- `assets/classic-route-atlas.json`：全256コースの実形状。`node tools/build-classic-atlas.mjs` で再生成。
- `legacy.html`：従来URLから標準版への案内。
- `reborn.html` / `assets/remake/`：前回の別エンジン版。
- `.github/workflows/auto-merge.yml`：検証後の自動統合。
- `.github/workflows/pages.yml`：検証付き公開。

更新ファイルZIPは既存のActions **Download full and changed-files ZIPs** で生成できます。素材の来歴とライセンスは `RIGHTS.txt`・`THIRD_PARTY_NOTICES.txt` を参照してください。
