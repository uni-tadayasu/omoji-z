# 尾文字Z / OMOJI Z — REBORN 4.0

ブラウザレーシングの新しいゲーム本体です。トップページを刷新し、描画・走行物理・入力・プロフィール・音声を独立したモジュールとして一から実装しました。サーバーやビルドなしで静的配信できます。

## REBORNで遊べる内容

- **6つの専用サーキット**：月光ベイサイド、蒼海コーストライン、白銀スカイライン、翠影フォレスト、霧氷ホワイトリング、黄昏アンバーウェイ。
- **512台の公開カタログ**を使用した新しい3D車両。車体形状、ガラス、ホイール、ライト、反射材質を生成。最初は3台を所有。
- 3台のCPUとのレース、タイムアタック、無制限フリー走行。1・2・3・5周と3段階のCPU難易度。
- 120Hz固定ステップによる加減速・操舵・ドリフト・ニトロ・壁接触・路肩減速、距離による周回判定。
- 車両検索、購入、カラー変更、エンジン・タイヤ・ブレーキ各3段階の強化。
- 合計タイムとベストラップ、走行報酬、所有車、記録、音量・画質の保存。JSONバックアップ書き出しと読み込み。
- PCキーボード、タッチボタン、標準ゲームパッド。3種類の走行カメラ、ポーズ、画面を離れた際の自動停止。
- ローカル配信のThree.js 0.180.0と既存のオリジナル音源。ゲーム実行時にCDNからライブラリを取得しません。

**旧256コース、オンライン対戦、グランプリ、公式戦、運営専用機能は[クラシック版](legacy.html)で利用できます。** これらを新エンジンへ移植済みと表記していません。新旧版はゲーム画面から切り替えられます。既存の車種・コースの静的解説ページも維持しています。

## セーブデータ

REBORNは `omoji-z.remake.v1` に保存します。初回のみ旧版の所持Zと公開車の所有権を読み取り、旧キーへは書き込みません。新しい物理条件なので旧強化・旧タイムの持ち込みは行わず、クラシック版にそのまま残します。以後、新旧版のZ・所有車は別々に進行します。REBORNの記録はベストラップを比較するので、異なる周回数でも比較対象が混ざりません。

同一ブラウザ・同一ドメインの保存です。別端末へは設定のバックアップを使ってください。保存が許可されていないブラウザでは警告を表示します。新しい版はWebGL2対応ブラウザが必要です。GPU機能が利用できないときはクラシック版への案内を表示します。

## ブランチからmainへ自動統合

今後はmainから作業ブランチを作成してpushすると、**mainと統合した状態のテストと公開用ファイル生成が成功した場合だけ**自動でmainへ取り込み、GitHub Pagesの公開を起動します。競合や保護ルールで拒否された変更は統合しません。具体的な条件と失敗時の確認先は[自動統合の説明](docs/AUTO_MERGE.md)を参照してください。

初回の導入PRだけは通常のマージが必要です。自動統合処理自体は信頼済みmainの版から実行します。公開ドメイン `omoji-z.com` と既存CNAMEは維持しています。

## 開発・検証

Node.js 22推奨。開発テストのDOM環境にjsdomを使います。ゲームを遊ぶ人にはnpmは不要です。

```sh
npm ci --ignore-scripts
npm test
npm run dev
python3 tools/build-site.py --out /tmp/omoji-public
```

`npm test` は新しい物理・入力・保存・音声・描画構造・画面接続・自動統合と、保持したクラシック版の既存検証を実行します。描画構造テストは実際のThree.js形状・材質・カメラを検査しますが、GPU画像の正しさや実機FPSを保証するテストではありません。

制作環境のブラウザではWebGLが無効のため、GPUによる実画面・スマートフォン実機の目視確認は未完了です。この制限はテスト成功と区別して記録しています。

## ファイル構成

- `index.html` / `assets/remake/`：新しいゲーム本体。
- `legacy.html` / 既存の `assets/game.js`：クラシック版。
- `tools/test-remake-*.mjs`：新しいエンジンの検証。
- `.github/workflows/auto-merge.yml`：検証後の自動統合。
- `.github/workflows/pages.yml`：検証付き公開。

更新ファイルZIPの作成は既存のActions **Download full and changed-files ZIPs** を利用できます。素材の来歴とライセンスはRIGHTS.txt・THIRD_PARTY_NOTICES.txt、旧版の詳細は[クラシック版の説明](docs/CLASSIC_V3.md)にあります。
