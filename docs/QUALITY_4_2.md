# CLASSIC REMASTER 4.2

基準: `0c30dafde41abdab8a6243f104036b6be1543c6d`（公開4.1）。

出走前の確認、入力の確実さ、描画の安定性を改善しました。

- 実際の256コースの座標図を拡大して表示。読み込み失敗時に再試行でき、遅れて返ったデータや閉じた画面の処理を整理。
- 初回読み込みの遅延・通信切断・エラーを表示。ゲーム本体の準備完了を確認してから出走操作を受け付けます。
- 設定をEscで閉じたりゲームパッドの割当ボタンを押したとき、背後のレースを再開させない入力制御。
- ハンドルやアクセルの押しっぱなしを解除し、閉じた直後もゲームパッドの押下エッジを維持。
- 影の投影位置を安定化し、画質・描画方式の切替で古い影バッファを使い回す問題を修正。
- 4K・8K・横長画面でも描画ピクセルの上限を適用。異なる画素密度のモニターへ移動した場合も再計算。
- 拡大ダイアログのフォーカス復元、キーボード境界、スマートフォンの表示と操作領域を改善。

## 検証

`npm test` は従来の全車両・走行・経済・保存・音楽・静的ページ・自動公開の検査に加え、`npm run test:quality` の起動、入力、描画、画面接続を実行します。

入力は実ゲームのメソッドを使って検証。描画はThree.jsの実カメラ・影バッファと数値上限を検証。画面はjsdomで選択・ダイアログ・エラー復帰を検証します。公開後はHTML、変更されたスクリプト、CSSの取得とハッシュを確認します。

この環境では実ブラウザ操作ツールが利用できません。実WebGLの見た目、実スマートフォンの操作感とFPS、複数実機対戦は今回の検証範囲に含まれません。

## 配布

既存の自動統合は作業ブランチをmainと合わせてテストし、成功後にmainへ取り込み、GitHub Pagesを公開します。今回の差分ZIPの標準基準は上記4.1コミットです。異なる旧版から更新する場合はActionsの`base_ref`に、その版のコミットを指定します。
