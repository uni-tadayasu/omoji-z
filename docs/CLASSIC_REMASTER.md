# 尾文字Z — CLASSIC REMASTER

今回の主役は、従来のフル機能版です。`index.html` がクラシック版の高品質リメイクを直接起動します。6コース版のREBORNを既定のゲームにはしません。

## 引き継ぐゲーム内容

| 内容 | 扱い |
| --- | --- |
| 公開512車・運営専用3車 | 元のカタログと利用条件を維持 |
| 全256コース | 元のコース・距離・判定を維持 |
| 通常レース・タイムアタック・練習 | 元の走行とルールを維持 |
| 公式戦・グランプリ | 元の進行・報酬を維持 |
| 対戦・リンク記録 | 元の接続と互換性を維持 |
| ガレージ・ショップ・塗装・強化 | 元の所持車・価格・保存データを使用 |
| 運営機能 | 元の入力・利用条件を維持 |

画面の見せ方と描画品質を改善しながら、既存の機能に接続されたコントロールを残します。旧HTMLの249個のID、26個の入力契約、73個の操作用属性と8つのメニューの互換性を検証しています。

## 画面の改善

- PCでは常設ナビゲーションから全8メニューへ移動し、スマートフォンでは横スクロールのナビゲーションを使います。
- 出走パネルへ実コースの形状から生成したコース図・距離、現在のモード・変速方式・CPU設定を表示します。
- コース図を読み込めない場合は、既存のコースイメージを表示します。コース選択や走行には影響しません。
- Alt＋1～8でメニューを切り替えられます。入力中やダイアログ表示中には割り込みません。

## セーブとURL

- 既存の `omojiz.economy.v1`、`omoji-z.settings.v1`、v3記録などを従来どおり利用します。
- REBORNの別セーブ `omoji-z.remake.v1` を、クラシック版の所持Zや記録へ自動上書きしません。
- `legacy.html` のブックマークは、コース・車両のクエリと画面位置のハッシュを保って `index.html` へ移動します。
- 車種・コース詳細ページの既存 `?car=` / `?course=` リンクも、フル機能版を開きます。
- REBORNは比較用の `reborn.html` に残します。独立したゲームとセーブであり、クラシック版の代替ではありません。
