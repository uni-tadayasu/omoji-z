The dependency versions below are supported by the official v1.5.5 lockfile
and exact comparisons of the published browser source map's sourcesContent
against the corresponding npm release files. All 15 bundled dependency
source files matched. See inventory.json for provenance and hashes.

@msgpack/msgpack is a declared dependency used by the separate optional
serializer.msgpack.mjs artifact. That serializer and MessagePack code are
not in this distributed browser asset. Its notice is included as an
informational appendix; it is not represented as bundled game code.

The existing assets/peerjs-LICENSE.txt, assets/THREE-LICENSE.txt and
assets/fonts/OFL.txt are retained separately. This inventory's scope is
PeerJS and the dependency code in that browser bundle.
