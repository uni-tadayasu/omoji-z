尾文字Z GitHub Pages版

1. ZIPを展開します。
2. GitHubで公開するリポジトリを開き、「Add file → Upload files」へ進みます。
3. 展開した中身をまとめてドラッグし、「Commit changes」を押します。
   index.html と assets フォルダーがリポジトリの一番上にある状態にします。
   .nojekyll も一緒にアップロードしてください。
4. 「Settings → Pages → Build and deployment」で
   「Deploy from a branch」→「main」→「/(root)」を選び、「Save」を押します。
   アップロードしたブランチが main 以外なら、そのブランチを選びます。
5. 同じ設定ページに公開URLが表示されたら開きます。

SNS共有カードは実際の公開先 https://uni-tadayasu.github.io/omoji-z/ と、画像 assets/ogp-share.jpg に設定済みです。
同じリポジトリにアップロード後、SNSにはゲームの公開URLを貼り付けてください。古い表示がキャッシュされている場合は、SNS側が新しい情報を取得するまで時間がかかることがあります。
別の公開URLに移す場合は index.html の絶対URLをその公開先に変更してください。

通常旧車207台、121コース、レース用ユーロビートリミックス6曲、メニュー専用BGM「Midnight Apex」1曲、CPU峠バトル・タイムアタック・ドリフト・練習走行を収録。
「潮騒ストレート」3.0kmと「白銀ストレート」10.0kmでは加速と最高速を試せます。
ボーナスステージ98コースを収録。完走ごとに6,500 Z〜38,500 Zの追加Z（強化ボーナス適用前）を獲得できます。
「コースを表示」からボーナス全件を表示でき、コース種別と地形で絞り込めます。
ショップではZで旧車やガレージに取り付ける部品を購入できます。購入した車はガレージで選択できます。
ガレージでは5種類の部品を最大Lv.100まで強化できます。国・年代・キーワードで車種を絞り込めます。
壁に当たると外向きの速度が吸収され、壁沿いに減速します。
レース設定でAT / MTを切り替えられます。MTはQでシフトダウン、Eでシフトアップ。
スマホでは「− / ＋」、標準ゲームパッドでは左 / 右ショルダーで変速できます。
ニトロはアクセルと同時に Shift または標準ゲームパッドの右フェイスボタンを長押しします。
スマホは画面の NITRO を長押し。満タンから合計約5.5秒使え、次のレースで補充されます。
ガレージの「運営車両」で専用キーを入力すると2026年型のマイバッハ S 680をモチーフにした運営車両を解放できます。
解放状態はこのブラウザに保存されます。公開サイト用の管理者認証としては使用できません。
記録・Z・強化は端末のブラウザに保存されます。URLが変わると別の保存領域になります。
最初のクリックやタップでメニューBGMが始まります。BGM欄でオン・オフを切り替えられます。
メニュー、ガレージ、設定、走行中の画面で、専用アイコンと薄い背景イラストが表示されます。
GitHub Pagesは静的ファイルを配信するため、この版にはフリールームとランクマッチがありません。
Cloudflare、データベース、Node.jsの設定は不要です。
