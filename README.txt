尾文字Z｜上書きアップロード専用版

■ 更新（既に同じGitHub Pagesで公開している場合）
このZIPを展開し、展開した中身を既存ページと同じブランチ・階層に上書きアップロードしてください。index.html と assets が同じ階層に置かれていれば完了です。ゲームの公開元の設定、GitHub Actions の追加、Issues・Discussions の有効化、外部サーバー、ログイン設定は不要です。
更新はGitHub Pagesに反映された後、普段のURLを再読み込みすると確認できます。同じURL・同じブラウザーの既存セーブを使えます。キャッシュによって表示が古い場合は、PCなら Ctrl+F5 で再読み込みできます。

■ 収録機能
・全123コース、CPUレース・タイムアタック・ドリフト・練習走行、PC・スマホ対応。旧車207台、現代の日本車49台、スーパーカー53台と専用運営車1台を収録。新型車・スーパーカーは車種をモチーフにしたゲーム用3Dモデルで、性能はゲーム用に調整しています。
・ガレージとショップはカテゴリで絞り込めます。ショップでは価格・年式・最高速で並び替え、購入前に車両性能を見られます。所持Zはメニューのヘッダーとレース画面上部に表示します。
・峠バトルのCPUは5段階です。上級はコーナーの立ち上がり、達人は進入・追い抜き、伝説はライン取りとニトロの判断を強化しています。
・100 km耐久の完走報酬は100万 Z。一時停止メニューでリタイアを確定すると、到達1 kmにつき5,000 Z（最大495,000 Z）を受け取れます。
・「フレンドと対戦」→「短いコードで部屋を作る」で、ホストが10文字の部屋コードを発行します。ゲストはそのコードを入力して「部屋に参加」を押します。ホストは必要に応じて「CPUを1台追加」で空き枠を埋め、レースを始められます。ホスト・ゲスト・CPUを合わせて最大8台です。初めての接続は2名の人間で試し、必要に応じてCPUを追加してください。100 km耐久はソロ専用です。
・短いコードは外部のPeerJS Cloud（無料サービス）に接続情報の交換を任せます。設置やアカウント登録は不要です。サービスが利用できない場合は「招待と返信で接続する」を選べます。WebRTCの直接接続が制限されている回線では、招待と返信でもつながらない場合があります。接続候補の取得には公開STUNを使い、ゲームの走行データは参加者のブラウザー間で送ります。直接接続用のコードには接続情報が含まれるため、対戦相手だけに共有してください。対戦中はタブを開いたままにしてください。
・1人で複数のCPUと対戦する場合は「CPUと走る部屋を作る」を使えます。対戦後、ホストが「部屋に戻る」を押すと、同じ部屋から次のレースを始められます。
・峠バトルとCPUを追加したフリールームでは、レース開始時に通常車両からCPUの車種を抽選します。1つのフリールーム内でCPUの車種は重複しません。タイムアタック、ドリフト、練習走行は従来どおり単独で走ります。
・「記録・対戦」で、プレイヤーレベル・総XP・Z報酬倍率を確認できます。Lv.1は1倍、レベルが1上がるごとに基準額の5%分が増え、Lv.81で上限の5倍です。通常コースの完走報酬とボーナスステージ、フリールームの完走に適用します。完走で上がったレベルは次の報酬から反映されます。100 km耐久の完走・リタイア報酬は固定です。
・運転アシストを使わずにタイムアタックを完走すると、「自己記録」の「タイムアタック対戦リンク」で自己ベストを共有できます。相手がURLを開くと、同じコースと目標タイムに挑戦できます。連絡手段には普段お使いのメッセージアプリ等を使ってください。
・受け取った対戦リンクを「リンク対戦の順位表」に貼り付けると、自分と相手のタイムをコース別に比較できます。順位表は追加したこのブラウザーに保存されます。リンクは自己申告相当のタイムで、本人の身元やタイムの正当性を検証する仕組みはありません。
・「記録・対戦」→「セーブデータ同期」で、所持Z・XP、所有車・強化・塗装・ニックネーム、自己記録と基本設定を別端末へ移せます。元の端末で同期コードをコピーするかファイルを書き出し、受け取った端末で読み込んで内容を確認してください。取り込み前のセーブは復元用に保管されます。端末間で自動更新する方式ではありません。操作デバイスの割り当て、運営車両の解放、部屋情報は端末ごとに保管します。
・上部のお知らせは従来どおり表示します。内容を更新したい場合のみ announcements.json を編集してください。

世界順位の自動集計、自動ランクマッチ、ゲーム内チャット、フレンド・ギルド管理はこの版に含まれません。
