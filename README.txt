尾文字Z｜上書きアップロード専用版

■ 更新（既に同じGitHub Pagesで公開している場合）
センチュリーロイヤル操作性改善版を反映済みの公開フォルダーへ、このZIPを展開して中身を同じ階層で上書きしてください。assets 内の更新ファイルは、既存の assets フォルダーへ入れてください。
GitHub Pagesへ反映された後、いつものURLを再読み込みしてください。同じURL・同じブラウザーの既存セーブを使用できます。

■ BGM「Cityline」
・メニューBGM「Cityline Ignition」の雰囲気に合わせ、全127曲のレース用インストを制作しました。メニュー1曲とレース127曲の曲名・曲IDを保持しています。
・「設定」→「BGM」で試聴・選曲できます。自動選曲はコースの雰囲気に合う曲を中心に共通曲も再生し、直前の自動選曲と同じ曲を避けます。
・メニューの「Cityline Ignition」は Stability AI の Stable Audio 3 で生成・編集した既存音源です。 https://huggingface.co/spaces/stabilityai/stable-audio-3
・ZIP内の更新ファイルをすべて同じ場所へ上書きしてください。assets/audio 内のファイルは個別のMP3です。

■ ニトロの回復
・全レースはニトロ満タンで始まります。ニトロを離して2秒経過後、10 km/h以上で前進している間に回復します。
・回復はLv.0で毎秒4.0%、1 Lvごとに毎秒0.3ポイント加算、Lv.15で毎秒8.5%です。ガレージの「ニトロレベル」で現在の回復速度を確認できます。

■ 公式戦・走行中の表示
・メニューの「公式戦」から出走します。ソロはCPU3台、マルチは部屋コードで2〜4人が集まり空き枠にCPUを入れます。いずれも全4台。コースとCPU車種はレースごとに抽選します。
・1位は25,000 Z・30 pt、2位は15,000 Z・18 pt、3位は7,000 Z・8 pt、4位は0 Z・0 pt。公式戦ポイントで10級から1級、初段から10段へ昇格します。進行はブラウザーに保存されます。
・運営車両の「性能MAX」は公式戦に適用されません。
・走行中に車の上へニックネームと称号を表示します。マルチでは全参加者が、画面内にいる対戦車の同じ表示を確認できます。

■ 今回の更新
・「レース」→「コース・モードを選ぶ」→「峠バトル」でCPUを1〜7台選べます。初期値は1台です。対戦車種はレース開始ごとに抽選します。タイムアタック等の単独モードは従来の競技ルールです。
・「設定」→「画面・運転」で追従カメラの距離を選べます。自動は画面サイズに合わせて調整されます。高速時の舵の微調整とスマホの指のスライドにも対応しました。
・車の塗装、ガラス、接地する影、道路の路面・陰影を見直しました。描画方式や品質の設定に応じて表現が変わります。
・トップの新作CG、ガレージCG、メニューごとの配色とアイコンを更新しました。
・運営専用マイバッハとロールスロイスで「性能MAX」をオンにできます。ソロ試走用です。試走の報酬と記録は保存されず、オフにすると通常性能に戻ります。

■ 旧版からの引き継ぎ
これまでの所持Zと走行記録を引き継ぎます。外れた試験コースの走行記録は「旧収録コース」として閲覧できます。前版の車両はすべて引き継ぎます。強化済み部品は今のステージ内の進行割合に合わせて換算します。☆は16、車両レベルは8まで引き継ぎます。

■ グランプリ
・メニューの「グランプリ」に全16大会を収録。1大会で8ステージを連続して走行し、プレイヤー1台とCPU7台が順位ポイントを競います。
・順位ポイントは1位 25点、2位 18点、3位 15点、4位 12点、5位 10点、6位 8点、7位 6点、8位 4点。合計ポイントで優勝が決まり、同点なら各順位の回数を上位から比較し、それも同じなら最終戦の順位で決まります。
・優勝した大会ごとの称号と、全16大会制覇の特別称号を獲得できます。グランプリ画面で表示する称号を選べます。メニューヘッダー・走行画面・総合順位でプレイヤー名の横に表示します。
・表示する名前と完走したラウンドを、このブラウザーに自動保存します。大会画面から次のラウンドを再開できます。

■ マイバッハのモデル差し替え
・ガレージの「運営車両」で、既存のマイバッハを選択できます。運営キー、車両データ、強化、ニックネームは同じものを使います。
・高精細表示には添付モデルの1,898,417三角形と4Kテクスチャ3枚を収録しています。軽量描画用に、同じ車の軽量モデルも収録しています。
・ロールスロイスも同じ運営キーで選べます。

■ UI刷新とレース復旧
・トップの新作CG、オリジナルアイコン、新ロゴ、所持Z付きのメニューに刷新しました。図鑑・ガイド、レースの計器・確認画面にも新しい配色とアイコンを反映しました。
・メニュー項目の折り返しを抑え、スマホのガレージから所有車・強化・整備・運営車両へ直接移動できるようにしました。
・3Dレースの初期化に失敗した場合は、同じレースを軽量描画で再試行します。グランプリの進行と所持Zはこれまでのセーブを読み込みます。
・コース選択とロード画面の画像パスを修正しました。

■ これまでの主な更新
・運営車両「ロールスロイス」を追加しました。ガレージの「運営車両」で既存の運営キーを使うと、マイバッハとロールスロイスの両方を選べます。解放済みの場合は再入力不要です。
・ロールスロイスの高精細表示では添付モデルの1,900,248三角形と元のテクスチャを使います。低画質やソフトウェア描画を使う端末には、同じモデルを元にした軽量形状を使用します。
・グランプリの順位集計、結果保存、報酬処理、次戦の再開を修正しました。
・ショップの特別販売に「omoji Z」を追加しました。基礎性能は1,000 km/h・5,000 PS、価格は30,000,000 Zです。外観は現行クラウン セダンをモチーフにしています。
・メニューの「塗装屋」で所有車ごとのボディカラーを変更できます。
・トップ、ガレージ、ショップ、グランプリ、記録・対戦、設定および図鑑のデザインを刷新しました。
・走行中の車体とコースの材質、光と遠景を見直しました。端末の描画方式に応じて表示が変わります。
・ステアリング入力と高速域での車体の安定性を調整しました。
・メニュー曲を含め、BGM全128曲のメロディー、コード進行、楽器編成を組み直しました。

■ 収録機能
・ホーム、プレイ画面、ガレージ、ショップ、記録、設定、コース／車両図鑑と操作ガイドを新しいCGとアイコンで統一。図鑑では検索に加え、カテゴリや並べ替えを利用できます。
・無限テクニックサーキットはソロ専用。終わりのない周回で、ドリフト・コーナリング・高速走行の技術に応じて走行中にZを獲得します。
・車体の破損がガレージに反映され、4種類の整備で部位ごとに修復できます。
・追従カメラはPCで少し近く、スマホで少し離れます。画面の縦横比に応じて自動調整します。
・追加した154台は、ゲームオリジナルの車種とグレードです。
・上部メニューは「レース」「グランプリ」「ガレージ」「塗装屋」「ショップ」「記録・対戦」「設定」の7項目です。初期画面には選択中のコース・車・モードとレース開始ボタンを表示します。変更するときは「コース・モードを選ぶ」を開いてください。
・スマホのレース画面では、長押しによる文字選択や拡大鏡、連打・複数指操作による誤ズームを抑えます。一時停止や結果画面は縦にスクロールできます。メニューでは文字の選択・コピーとピンチ拡大が使えます。
・「レース」の日替わり・週替わりミッションは各7種類が順に切り替わります。日本時間の毎日0時と月曜0時に更新し、達成時にZ・XPを付与します。
・コース・所有車をお気に入りに登録できます。完走した直近8件の異なるソロコースで絞り込んだり、自己記録から同じ条件を選び直したりできます。お気に入りと履歴は端末ごとに保存します。
・パラパラMIXのオリジナル・ユーロビートを全128曲収録（メニュー1曲、レース127曲）。「設定」→「BGM」で試聴・選曲できます。別アプリ・タブへの切替時は音を停止し、ページを閉じるときは音源も解放します。
・全256コース、CPUレース・タイムアタック・ドリフト・練習走行、PC・スマホ対応。車両図鑑には公開車両512台（うちオリジナル車1台）を掲載。新型車・スーパーカーは車種をモチーフにしたゲーム用3Dモデルで、性能はゲーム用に調整しています。
・ガレージ・ショップで64部品を個別強化できます。一括強化は部品ごとの費用と到達レベルを確認してから確定します。全64部品がLv.32に達すると☆ランクが上がります。☆16に達すると昇格が完了し、その時点のLv.32を維持します。車両レベル、車両XP、車両ステージは引き継ぎます。
・「ガレージ」→「タービン強化」で所有車を個別にLv.0からLv.24まで強化。1 Lvごとに公称最高速度+20 km/h、加速+30ポイント（Lv.24で+480 km/h、+720ポイント）。最初は1,000 Z、全24回で1,097,640 Zです。ソロ・フリールームの走行に反映されます。
・「ガレージ」→「ニトロレベル」は所有車別にLv.15まで強化可能。ニトロ噴射中の最高速度は1 Lvごとに+25 km/h（最大+375 km/h）。対応モードはソロ・グランプリ・フリールームです。Lv.1は1,000 Z、Lv.15まで合計219,750 Z。
・車の強化や速度に応じて、高速域の操舵・制動・変速を補正します。ATとMTで同じ車両調整を適用し、MTは手動で変速できます。
・完走した車に車両XPが入ります。車両レベルが1上がるごとに公称最高速が5 km/h伸びます。上限はLv.8（Lv.1から合計+35 km/h）です。レベルの速度加算はソロで有効です。フリールームでは部品の強化を使用し、車両レベル加算は適用しません。
・発進、制動、旋回、グリップ、最高速、ニトロの試験コース12本を収録。試験コースや練習走行の完走後に計測結果を表示し、同じ条件での前回値と比較できます。
・レース設定の「経験値コース」に120本を収録。ソロで完走すると、通常のXPに加えて121〜4,200 XPを毎回獲得できます。途中リタイア時は経験値コース分の加算はありません。
・ガレージとショップはカテゴリで絞り込めます。ショップの「外観と性能を見る」で車体を回転して確認できます。価格・年式・最高速で並び替えられます。所持Zはメニューのヘッダーとレース画面上部に表示します。
・峠バトルのCPUは5段階です。上級はコーナーの立ち上がり、達人は進入・追い抜き、伝説はライン取りとニトロの判断を強化しています。
・30 kmの直線コースを各カテゴリ1本追加しました。黎明高原ロングストレートは完走XPに4,200 XPを追加し、湾岸光路ロングストレートは完走Zに固定120万Zを追加します。どちらもソロ専用です。
・100 km耐久の完走報酬は100万 Z。途中でリタイアを確定すると、走破した1 kmごとに報酬が入ります。1〜10 kmは1,600 Z、11〜40 kmは3,400 Z、41〜99 kmは5,200 Zずつ加算され、99 kmで合計424,800 Zです。
・「フレンドと対戦」→「短いコードで部屋を作る」で、ホストが10文字の部屋コードを発行します。ゲストはそのコードを入力して「部屋に参加」を押します。ホストは必要に応じて「CPUを1台追加」で空き枠を埋め、レースを始められます。ホスト・ゲスト・CPUを合わせて最大8台です。100 km耐久と経験値コースはソロ専用です。
・短いコードは外部のPeerJS Cloud（無料サービス）に接続情報の交換を任せます。設置やアカウント登録は不要です。サービスが利用できない場合は「招待と返信で接続する」を選べます。WebRTCの直接接続が制限されている回線では、招待と返信でもつながらない場合があります。接続候補の取得には公開STUNを使い、ゲームの走行データは参加者のブラウザー間で送ります。直接接続用のコードには接続情報が含まれるため、対戦相手だけに共有してください。対戦中はタブを開いたままにしてください。
・1人で複数のCPUと対戦する場合は「CPUと走る部屋を作る」を使えます。対戦後、ホストが「部屋に戻る」を押すと、同じ部屋から次のレースを始められます。
・峠バトルとCPUを追加したフリールームでは、レース開始時に通常車両からCPUの車種を抽選します。1つのフリールーム内でCPUの車種は重複しません。タイムアタック、ドリフト、練習走行は従来どおり単独で走ります。
・通常レースの完走報酬は、コースの距離とレース結果に応じて決まります。Zボーナスコースはコース分のZが加算されます。
・通常レースの基礎Zと通常Zボーナスの追加額は前版の6倍。無限テクニックの基礎Zとミッション報酬Zは前版の4倍です。
・「記録・対戦」でプレイヤーレベルとZ報酬倍率を確認できます。Lv.1は1倍でLv.51まで毎レベル+0.07、Lv.51で4.5倍です。その後は毎レベル+0.035で、Lv.151からは8倍です。完走で上がったレベルは次の報酬から反映されます。
・64部品をすべてLv.0からLv.32に上げる費用は合計5,122,050 Z。車両ステージの解放費は別途必要です。車両価格と整備費は現行の設定を使用します。
・ミッション達成報酬と百里耐久ハイウェイの完走・途中報酬は固定です。百里耐久ハイウェイの完走では基礎950 XPも受け取れます。
・運転アシストを使わずにタイムアタックを完走すると、「自己記録」の「タイムアタック対戦リンク」で自己ベストを共有できます。相手がURLを開くと、同じコースと目標タイムに挑戦できます。連絡手段には普段お使いのメッセージアプリ等を使ってください。
・受け取った対戦リンクを「リンク対戦の順位表」に貼り付けると、自分と相手のタイムをコース別に比較できます。順位表は追加したこのブラウザーに保存されます。リンクは自己申告相当のタイムで、本人の身元やタイムの正当性を検証する仕組みはありません。
・「記録・対戦」→「セーブデータ同期」では、同期元の端末で発行したペアリングコードを受信端末に1回入力できます。初回の内容を確認して反映すると、両方のゲーム画面を開いている間は、同期元から所持Z・XP・所有車・強化・走行記録が自動で送られます。レース中に受信したデータはメニューに戻ってから反映します。受信側の進行も更新されていた場合は上書き前に確認します。接続にはPeerJS Cloudと公開STUNを使います。ページを閉じている間や回線が直接接続を許可しない場合は自動同期できません。
・自動同期はペアリングリンクでも設定できます。受信端末で開くと接続コードが入力されます。受信側で同期を承認するとミッション進行も届きます。手動の同期コードやファイルも利用できます。車体色・ニックネーム・基本設定の移行には手動同期を使ってください。取り込み前のセーブは復元したりファイルに保存したりできます。操作デバイスの割り当て、運営車両の解放、部屋情報は端末ごとに保管します。
・フッターから遊び方、コース一覧、車種一覧を開けます。3つともJavaScriptなしで読めます。公開ページの一覧は sitemap.xml に収録しています。
・上部のお知らせは従来どおり表示します。内容を更新したい場合のみ announcements.json を編集してください。
