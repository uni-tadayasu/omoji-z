■ 更新（既に同じGitHub Pagesで公開している場合）
このZIPを展開し、展開した中身を既存ページと同じブランチ・階層に上書きアップロードしてください。index.html と assets が同じ階層に置かれていれば完了です。ゲームの公開元の設定、GitHub Actions の追加、Issues・Discussions の有効化、外部サーバー、ログイン設定は不要です。
更新はGitHub Pagesに反映された後、普段のURLを再読み込みすると確認できます。同じURL・同じブラウザーの既存セーブを使えます。キャッシュによって表示が古い場合は、PCなら Ctrl+F5 で再読み込みできます。

■ 収録機能
・全123コース、CPUレース・タイムアタック・ドリフト・練習走行、PC・スマホ対応。ガレージ、チューニング、ニトロ、AT/MT、ショップの購入前性能確認を収録しています。
・100 km耐久の完走報酬は100万 Z。一時停止メニューでリタイアを確定すると、到達1 kmにつき5,000 Z（最大495,000 Z）を受け取れます。
・「フレンドと対戦」で、招待制のフリールーム（ホスト1人と参加者最大7人）を作れます。ホストが耐久以外のコースを選んで部屋を作り、各ゲストに招待コードを送ります。ゲストは招待コードを貼り付けて返信を送り、ホストがその返信を貼り付けます。接続したらホストがレースを開始します。複数人の場合は1人ずつ繰り返してください。
・フリールームのコードは接続情報を含むため、対戦相手だけに共有してください。対戦中はホストもゲストもゲームのタブを開いたままにしてください。WebRTCが接続先を調べる際はGoogle・Cloudflareの公開STUNを利用します。アカウントや設定は不要で、レース通信はブラウザー間で直接行われます。中継が必要な回線では接続できません。同じWi-Fiや別の回線、または下記のタイムアタック対戦リンクを利用できます。
・「記録・対戦」で、このブラウザーのプレイヤーレベルと総XPを確認できます。
・運転アシストを使わずにタイムアタックを完走すると、「自己記録」の「タイムアタック対戦リンク」で自己ベストを共有できます。相手がURLを開くと、同じコースと目標タイムに挑戦できます。連絡手段には普段お使いのメッセージアプリ等を使ってください。
・受け取った対戦リンクを「リンク対戦の順位表」に貼り付けると、自分と相手のタイムをコース別に比較できます。順位表は追加したこのブラウザーに保存されます。リンクは自己申告相当のタイムで、本人の身元やタイムの正当性を検証する仕組みはありません。
・上部のお知らせは従来どおり表示します。内容を更新したい場合のみ announcements.json を編集してください。

世界順位の自動集計、自動ランクマッチ、ゲーム内チャット、フレンド・ギルド管理はこの版に含まれません。
