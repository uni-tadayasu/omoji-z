OMOJI Z オリジナル合成BGM

assets/audio/parapara-000.mp3〜parapara-127.mp3 は、この版で
新たに生成した128個のスコアです。000はメニュー、001〜127はレース用です。
既存曲の録音、旋律、MIDI、サンプル素材を取り込まず、tools/compose-audio.py の
数式波形とシード別スコアから音を合成しています。以前の同名音源は使用しません。

構成
・各32小節。テーマ提示、応答、中間部、フルパートへの復帰。
・スケール、キー、和音進行、旋律、音色、打楽器パターンをスコアごとに設定。
・リード、パッド、アルペジオ、ベース、キック、スネア、ハイハットを合成。
・ステレオ配置、循環ディレイ、短い反射音、サイドチェイン処理。
・MP3 / ステレオ / 32 kHz / 96 kb/s。再生時の合成負荷はありません。

音源作成の記録
assets/audio/original-score.json にBPM、長さ、シード、スケール、和音進行、
旋律の基礎パターン、ファイルのSHA-256を保存しています。
ソース長は小節に揃え、音の余韻を先頭へ循環させています。
MP3の完全な隙間なしループ可否はブラウザーの実装に依存します。

再生成（制作時だけ必要）
Python 3、NumPy、ffmpeg（libmp3lame対応）を用意し、リポジトリのルートで実行します。
  python tools/compose-audio.py --jobs 4
一部だけ生成する場合：
  python tools/compose-audio.py --track 0 --track 80
ゲームを公開・プレイするためにこれらの制作ツールを導入する必要はありません。

スコアの長さやタイトルを変えた場合は、assets/game.js 内のZrとQnも
original-score.json の値へ合わせ、音源のキャッシュ版Kxを更新してください。
